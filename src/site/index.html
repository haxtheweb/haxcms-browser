Install and work offline

HAX is loading from the web each time. Install it, or make it available offline, to open it without a connection.

To install on iPhone or iPad: tap Share, then Add to Home Screen.

Reset the app

Reset the app removes the offline copy and the service worker and starts again from the web. Your sites are not touched.

Keep going with HAX

What you make here is an ordinary HAXcms site. Install HAX to keep working on it with the HAX CLI, Node.js, PHP, the desktop app or your coding agent.
