Install and work offline

HAX is loading from the web each time. Install it, or make it available offline, to open it without a connection.

To install on iPhone or iPad: tap Share, then Add to Home Screen.

Reset the app

Reset the app removes the offline copy and the service worker and starts again from the web. Your sites are not touched.

Sign in

Sign in with an account you already have. Your name, email and picture are filled in as the author of the sites you make next. HAXcms keeps the sign-in in this tab only.

Sign-in isn't set up on this copy of HAXcms. Whoever runs it can turn providers on (see docs/providers.md in haxcms-browser).

Save to the cloud

Keep your sites in cloud storage you already have, so they aren't tied to this browser. HAXcms only uses its own folder there.

Nextcloud or another WebDAV server

Use an app password, not your main one. The server has to allow this page to reach it (for Nextcloud, the WebAppPassword app with this page's address added). Kept in this tab only.

Publish a site

Put a site on the web for free. What gets published is the same as publishing with the HAX CLI.

You're offline. Publishing needs a connection; your sites are saved here and can be published when you're back online.

Publishing from the browser needs the publish service that runs on browser.hax.cloud, and this copy doesn't have one. Use Download site in the dashboard instead, then publish the folder with the HAX CLI (hax site site:surge).

A Waypoint is where a site goes next: somewhere that stores it, puts it on the web, or both.

Used for the repository, project or site name. Publishing with the same name again updates it.

The web address of the Waypoint server you beam to. A window opens there so you can sign in and allow this. You never type a password or token here.

The name becomes the site's web address on that Waypoint: 3 to 40 characters, a lowercase letter, then lowercase letters, numbers or hyphens. Broadcasting to a name you already have replaces what is there; the earlier version can be put back from the Waypoint.

Beam sends the site to the Waypoint. Broadcast makes it live at its web address. Left unticked, this does both.
